  • 导入并阅读 EPUB / TXT 英文电子书。
  • 点选查词：点一下单词，弹窗显示词性、音标与中文释义。
  • 段落划线标注：点段落前「译」按钮，用虚线划出重点词并在下方标注释义。
  • 主题与排版自定义：浅色 / 深色 / 护眼主题、字号、颜色、阅读壁纸、翻页方式。
  1. 打开 App 进入「书架」，点开一本预置样书体验。
  2. 配置 API Key：进入「用户」→「设置」→「翻译 API 配置」，填入模型 Key 并保存（启用 AI 查词与段落标注）。默认使用 DeepSeek，Key 获取请跳转 https://platform.deepseek.com/api_keys
  3. 点正文中的单词查词：弹窗显示词性、音标与释义；点「详情」查看完整词条（音标 / 多义项 / 例句 / 常用词组搭配），可「刷新」重新查询或「网页搜索」跳转浏览器。未联网时也能用内置离线词典查词。
  4. 点段落前「译」按钮：用虚线划出重点词并按词频上色（高频灰 / 中频蓝 / 低频红），词下标注中文释义；点已译段落里的单词「详情」，会附带该段的「段落赏析」（语法词句分析）。
  5. 查词方式可在「设置」选择：联网优先 / 本地优先（本地优先断网也能查词）。
  6. 导入自己的书：回到书架，点右下角「+」，选择 EPUB / TXT 文件。
  • 四色分类标注：按词性 / 是否查过 / 考纲 / 词频给划线标不同颜色。
  • 标注导出、多模型切换。
  • 更多能力：PDF、语音朗读（TTS）、背单词复习、书城、账号同步等。
