## 软件类型判定（叠加）
- **消费应用（ToC）**：面向 C 端英语阅读用户，走应用商店分发。
- **客户端应用**：交付形态为 iOS + Android 原生/跨平台 App，受 App Store / 国内安卓渠道审核政策约束。
- **开源软件（Open Core）**：代码开源，部分高级功能订阅解锁。
- **AI / 大模型应用**：核心翻译能力依赖大模型 API（BYOK，用户自带 key），模型成本不由开发者承担。
