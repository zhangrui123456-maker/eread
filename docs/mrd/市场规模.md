# 市场规模（Market Sizing）

日期：2026-08-27 · 口径：消费应用 + AI 应用 + 开源（Open Core）

## 上位市场（仅作背景，不作为目标 TAM）
中国英语学习软件市场在 2025–2031 年有持续研报覆盖，阅读是其中细分领域之一。但公开摘要未披露具体金额，多份报告以「亿元/%」占位。
- 来源：公开资料（6Wresearch《China Digital English Language Learning Market》、168report、龙讯等），查证日期 2026-08-27。
- 结论：**上位市场规模数字不可用，无结论**，不写进 TAM。

## 目标 TAM
产品 beachhead 为「大陆泛英语阅读爱好者」：不以应试为第一目标、持续阅读英文原版书/公版书的成年人/学生。该细分人群规模无权威一手数据。

**TAM 结论：无结论（证据不足）。**
- 原因：没有「中国泛英语原版书阅读者」这一细分人群的权威规模数据；上位市场（整体英语学习软件）数字也未公开披露。
- 不得用「英语学习者总数 × 假设渗透率」硬凑——缺两个关键参数（总人数、渗透率）的一级来源。

## SAM
在目标 TAM 内，通过 iOS + 中国大陆安卓渠道、中文界面、可自行导入英文原版书、愿自配模型 key 的部分用户。

**SAM 结论：无结论。**（取决于未量化的 TAM，且「愿自配 API key」的门槛进一步收窄人群，无数据。）

## SOM（首 1–2 年可实际拿到）
作为个人/开源项目，SOM 以「付费订阅人数」估算最诚实：
- 无一手转化数据，无法给出可信数字。
- **SOM 结论：无结论，需用户确认阈值。** 建议以「首年付费用户数」为验证指标而非收入规模（个人项目口径）。

## 单位经济（AI 应用口径）
BYOK 模式下，开发者不承担翻译/模型成本，毛利结构接近纯软件：
- 收入 = 订阅收入（Open Core 高级功能）。
- 主要成本 = 云/服务器（若做账号同步/词典缓存/更新分发）、开发者时间、应用商店抽成（App Store/Google Play 15–30%；大陆安卓渠道分成政策各异）。
- **模型成本 vs 售价**：本产品模型成本由用户自付，因此不存在「模型成本吃掉毛利」的 AI 应用典型风险；但「高级功能订阅」的定价上限受「用户已自付 key 成本」约束（用户总支出 = key 成本 + 订阅费）。

## 竞争参考定价（公开资料，2026-08-27 查证）
- 蒙哥阅读器（Meerkat Reader）：iOS 买断 €2.99 ≈ ¥18（公开资料）。
- 欧路词典 AI 超级会员：¥28/月、¥68/季、¥168/年（公开资料，中国区）。
- 沉浸式翻译：免费为主，会员 ¥69/月、¥588/年（Edge 插件页中文口径；App Store 海外区价格不同）（公开资料）。
- 彩云小译：VIP ¥12/月、¥108/年；SVIP ¥35/月、¥360/年（公开资料）。

**定价启示**：英语阅读/翻译类工具大陆用户对「月费 ¥10–30 / 年费 ¥100–170」区间接受度较高；买断 ¥18 也有先例。开源产品的订阅定价建议低于闭源竞品（见机会点对齐）。
