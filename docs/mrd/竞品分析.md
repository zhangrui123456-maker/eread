# 竞品矩阵（Competitors）

日期：2026-08-27 · 全部为公开资料，查证日期 2026-08-27

## 三层竞品结构

### 直接竞品（同为「英文原版书阅读 + 查词/翻译」的 App）

**1. 蒙哥阅读器（Meerkat Reader）**
- 定位：英文原著精读阅读器。
- 目标用户：英文原版书学习者（偏泛读/精读，非强应试）。
- 定价：iOS 买断 €2.99（约 ¥18），仅 iOS（公开资料；第三方「安卓版」包名与官方不一致，需谨慎）。
- 核心功能差异：一键/点选查词、Collins 词频分级颜色标注、四级/六级/GRE/托福/雅思/专四专八分类词频、生词本 + 遗忘曲线背单词、词频统计、EPUB/MOBI/PDF/TXT/DOC 导入、TTS。
- 护城河：买断价格极低、多年口碑（「英文精读神器」）。
- 已知弱点：无官方安卓版（第三方仿冒）；背单词/词频是主差异点但非「段译」；无大模型翻译/段译插入。
- **与本产品的差异**：本产品差异点①彩色虚线 + 虚线下小号字标注（视觉标注更细），②段落级译文插入，③大模型多模型翻译；本产品不主打背单词系统。

**2. 沉浸式翻译（Immersive Translate）**
- 定位：AI 双语对照翻译工具（网页为主，含 EPUB/PDF/TXT 文档翻译）。
- 目标用户：泛外语阅读/翻译用户（非纯电子书阅读器）。
- 定价：免费为主；会员 ¥69/月、¥588/年（Edge 中文口径）；海外 App Store 有 Pro/Max 多档（公开资料）。
- 核心功能差异：双语对照（原文+译文并排）、悬停翻译、EPUB/PDF/TXT 一键双语翻译导出、20+ 翻译引擎、自接 API、术语库。
- 护城河：2000 万+ 用户（官方口径，待验证）、多平台（Chrome/Edge/Firefox/Safari、iOS/Android、Mac/Win）、多引擎。
- 已知弱点：本质是「翻译工具」而非「阅读器」（无书库管理/阅读流/标注积累）；手机 App 功能少于浏览器版（第三方评测口径）；双语对照与「虚线小字标注」是不同交互。
- **与本产品的差异**：沉浸式翻译做「整篇/整段双语对照」，本产品做「逐词/逐词组彩色虚线标注 + 段译插入」，前者重「译文」，后者重「在原文上做学习标注」。

### 间接竞品（解决「英文阅读困难」的不同方式）

**3. 欧路词典 / 每日英语阅读（Eudic）**
- 定位：词典 + 阅读 + 背单词综合英语工具。
- 定价：增强版买断 ¥108（中国区）；AI 超级会员 ¥28/月、¥68/季、¥168/年；AI 资源 ¥12/10万词（公开资料，中国区）。
- 差异：屏幕取词/跨软件取词、长按查词、背单词、词频学习；「每日英语阅读」为内容订阅。
- 弱点：词典优先于阅读器，阅读标注能力弱于专精阅读器；AI 会员绑定欧路自有 AI 资源。

**4. KOReader（开源阅读器 + 插件生态）**
- 定位：开源多格式电子书阅读器（E-ink 墨水屏友好）。
- 定价：免费开源。
- 差异：内置 StarDict 词典即点即查；插件 KoTranslate（9 种翻译服务，可自接）、Offline Translate（本地划词翻译、虚线淡下划线「记住翻译」）、KOAssistant/AskGPT（AI 翻译/段译）。
- 护城河：开源社区、插件生态、跨设备。
- 弱点：移动端体验/UI 偏硬核、对普通用户门槛高；「虚线标注」仅作为翻译记忆提示，非系统化的分级着色标注。
- **重要信号**：KOReader 的 Offline Translate 插件已出现「已翻译短语加虚线淡下划线」交互（公开资料）——证明「虚线下划线提示」这一交互形态在读者中有需求，但与本产品「按词性/难度/是否点击的多分类彩色虚线 + 小字释义」在粒度与系统性上不同。

### 替代方案（非竞品，但用户正在用的方式）
- 纸质书 + 手动查词典/手机拍词翻译。
- 阅读 App（微信读书/Apple Books）+ 系统级取词翻译。
- 通用大模型 App（ChatGPT/豆包/DeepSeek）手动粘贴整段翻译。
- 网页版双语翻译后导出阅读。

## 竞争缺口机会
1. 「在原文上做**系统化、多分类的彩色虚线 + 小号字标注**」这一细分交互，蒙哥只做了「词频颜色高亮」，KOReader 只做了「翻译记忆虚线」，无人做「词性/难度/是否点击」多维切换的虚线标注 + 虚线下小字释义。
2. 「段落译文插入本段后」的连贯阅读形态，沉浸式翻译用「对照」，本产品用「插入」，是差异化选择。
3. 开源（Open Core）+ BYOK 的组合：代码开放、成本自担，区别于闭源订阅的欧路/彩云。

## 竞品结论
- 痛点（英文原版书查词/翻译摩擦）已被市场验证：蒙哥、沉浸式翻译、KOReader 均存在并运营。
- 但「多分类彩色虚线 + 小字标注 + 段译插入」的具体形态**无人精确复现**，差异化命题成立与否取决于交互是否真优于「高亮」「对照」（见假设 A1/A3 与验证计划）。
- 最大的竞品威胁不是「复制功能」，而是沉浸式翻译/KOReader 若快速跟进「虚线标注」形态（见 Red Team）。
