# Intake Gate

产品代号：`mobile-english-reader` · 日期：2026-08-27

## 一句话产品定义
一款手机英文电子书阅读器，核心是「便利的英文单词点查 + 基于大模型 API 的弹窗翻译」，并支持两种阅读标注模式：①单词/词组级——用不同颜色虚线划词、虚线下以小号字标注意思，颜色可按词性 / 是否点击查看 / 高考四六级等分类方式切换；②段落级——选中整段后在本段与下一段之间插入一段译文。

## 产品边界

**核心功能（首版包含）**
- 导入并阅读 EPUB / PDF / TXT 本地英文电子书。
- 点选单词/词组，弹窗展示翻译（调用用户自配大模型 API）。
- 模式一：单词/词组级彩色虚线划词 + 虚线下小号字标注意思；颜色分类方式可切换（词性 / 是否已点击查看 / 高考四六级分级 / 词频等）。
- 模式二：整段翻译，译文插入本段之后、下一段之前。
- 多模型可切换（国内模型为主，可配置海外模型）。

**不包含（首版不做）**
- 付费书城 / 内置正版书内容合作。
- 背单词复习系统（遗忘曲线、卡片、测试）——蒙哥/欧路的核心，非本产品差异点。
- 语音朗读/TTS、视频翻译、网页翻译、OCR 扫描翻译。
- 社交/打卡/社区。
- 开发者内置翻译额度（BYOK 模式下开发者不承担模型成本）。

## 交付形态
iOS + Android 移动 App（跨平台框架待定，见技术可行性）。

## 首版场景
用户将自己在别处获得的英文原版书（EPUB/PDF/TXT）导入 App，希望在不打断阅读流的情况下随时查词、看段译；通过彩色虚线与小号字标注，在原文页面上一眼看出单词的词性/难度/是否已查过，实现「边读边标注」的精读/泛读体验。

## 软件类型
开源软件（Open Core）+ 消费应用 + 客户端应用 + AI 应用，四类叠加。

## 目标用户 beachhead
泛英语阅读爱好者：不以应试为第一目标、持续阅读英文原版书/公版书的成年人或学生，有一定英语基础，愿意为「降低阅读摩擦」付费，但核心诉求是阅读体验而非背单词。

## 决策用途
个人 / 开源项目，验证「彩色虚线划词标注 + 段译插入」这一交互是否成立，同时探索可持续的 Open Core 变现路径。

## 资源约束
个人 / 兼职；无专职团队；需控制 MVP 工作量（1 人，业余时间）。

## 主要待验证缺口（进入 clarity 评分）
- 泛阅读爱好者群体规模与付费意愿无一手数据（需验证）。
- 「彩色虚线 + 小号字标注」是否真能提升阅读效率/留存，尚无验证。
- PDF 重排/划词的工程难度与 epub 差异大，需确认首版是否砍 PDF。
