# 机会点对齐（Opportunity Alignment）

日期：2026-08-27 · 核心机会点已由用户确认（见文末）

## 候选机会点（3 个，供用户押注）

### 候选 A：多分类彩色虚线 + 小号字标注（学习标注层）
- 一句话：把英文原版书变成「可视觉化的学习文本」——词性/难度/是否点击多维着色，虚线下小字释义，一眼看懂「哪些词我还没查、哪个词是什么词性、这个段落在讲什么」。
- 差异化：vs 蒙哥（只做词频高亮）、vs KOReader（只做翻译记忆虚线）、vs 沉浸式翻译（只做译文对照）。
- 风险：可能是「伪需求」（视觉噪音），需 V1 验证。
- 建议押注方向：**首版核心差异点**。

### 候选 B：段落译文插入（连贯阅读，不打断）
- 一句话：选中段落，译文直接插入本段之后，读原文不顺时眼睛下移即得译文，无需跳转侧栏/弹窗。
- 差异化：vs 沉浸式翻译的「对照式」。
- 风险：插入式 vs 对照式的优劣未验证；排版/重排成本。
- 建议：作为第二差异点，与 A 组合。

### 候选 C：开源 + BYOK 的极简纯阅读器（成本自担、代码透明）
- 一句话：主打「开源、免费、自接模型、隐私自控」的英文原版书阅读器，靠口碑而非商业化。
- 差异化：vs 闭源订阅的欧路/彩云/沉浸式翻译。
- 风险：商业可行性低（2/5），纯口碑项目；但契合「个人/开源项目」定位。
- 建议：作为「定位基调」，而非单一押注点。

## 建议的首版押注组合
**「A（多分类彩色虚线标注）为主 + B（段译插入）为辅 + C（开源 BYOK）为定位基调」**——三者叠加成一句差异化命题：

> 一个开源的英文原版书阅读器：在原文上，用**多维彩色虚线与虚线下小字**做学习标注，用**段译插入**做连贯翻译，模型成本由用户自接 API 承担。

## 建议放弃项（首版不做）
- 背单词复习系统（遗忘曲线/卡片/测试）——留给蒙哥/欧路。
- 付费书城 / 内置内容合作。
- PDF 精准划词（首版 PDF 仅整页翻译或砍掉）。
- TTS 朗读、视频/网页/OCR 翻译。

## 已确认决策（来源：用户输入，2026-08-27）
- 首版核心机会点：**A+B+C 组合**（A 为主、B 为辅、C 为定位基调）。
- 首版只支持 EPUB/TXT，砍掉 PDF。
- MVP Android 首发。
