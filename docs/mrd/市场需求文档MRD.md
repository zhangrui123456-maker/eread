# MRD：手机英文阅读器（mobile-english-reader）

日期：2026-08-27 · 状态：完整 MRD

## 1. 一页摘要

- **机会点一句话**：一个开源的英文原版书阅读器，在原文上用「多维彩色虚线与虚线下小号字」做学习标注，用「段译插入」做连贯翻译，翻译成本由用户自接大模型 API 承担。
- **目标市场**：中国大陆泛英语阅读爱好者（不以应试为第一目标、持续读英文原版书的成年人/学生）。TAM/SAM/SOM 因缺一手数据**无结论**（证据不足）。
- **差异化命题**：相比蒙哥（词频高亮）、KOReader（翻译记忆虚线）、沉浸式翻译（译文对照），本产品是**在原文上做系统化、多分类的彩色虚线标注 + 段译插入**，且以开源 + BYOK 降低信任与成本门槛。
- **Go/No-Go 建议**：**Explore**。技术 3/5、商业 2/5、痛点证据「中」。先跑 1 周内的 cheapest tests（交互对比 + 落地页 waitlist），通过后再投入 MVP 开发。

## 2. 产品定义

- **交付形态**：iOS + Android 移动 App（MVP 为 Android 首发）。
- **软件类型**：开源软件（Open Core）+ 消费应用 + 客户端应用 + AI 应用，四类叠加。
- **核心功能（首版）**：
  - 导入并阅读 EPUB / TXT 本地英文电子书（**首版不含 PDF**）。
  - 点选单词/词组弹窗翻译（用户自配大模型 API，BYOK）。
  - 模式一：单词/词组级彩色虚线划词 + 虚线下小号字标注意思；颜色分类可切换（词性 / 是否已点击查看 / 高考四六级分级 / 词频等）。
  - 模式二：整段翻译，译文插入本段之后、下一段之前。
  - 多模型可切换（国内 DeepSeek/通义/豆包/智谱为主，可配海外模型）。
- **不包含（首版）**：付费书城、背单词复习系统、TTS、视频/网页/OCR 翻译、PDF 精准划词、开发者内置翻译额度。
- **首版场景**：用户导入自有英文原版书，边读边查词、看段译；通过彩色虚线与小字标注在原文上一眼看出词性/难度/是否已查，实现「边读边标注」的泛读/精读体验。

## 3. 目标用户与 beachhead

- **Beachhead**：中国大陆泛英语阅读爱好者（非应试人群）。有基础英语能力，持续读英文原版书/公版书，能自行找到并导入电子书，愿为「降低阅读摩擦」付费，核心诉求是阅读体验而非背单词。
- **痛点**：查词/看译文会打断阅读流；现有工具要么「译文对照」（重译文、轻学习标注），要么「词频高亮」（粒度粗），缺乏「在原文上做多维学习标注」的连贯体验。
- **现有解决方案**：蒙哥（词频高亮+背单词）、沉浸式翻译（双语对照）、欧路（词典+取词）、KOReader（开源+插件）、通用大模型手动粘贴翻译。

## 4. 市场与 TAM/SAM/SOM

- **口径**：消费应用 + AI 应用 + 开源（Open Core）。
- **上位市场**：中国英语学习软件市场（阅读为细分），公开研报摘要未披露具体金额（公开资料，2026-08-27 查证）。
- **TAM**：无结论（证据不足）——缺「中国泛英语原版书阅读者」细分规模一手数据。
- **SAM**：无结论（取决于未量化 TAM，且「愿自配 API key」门槛进一步收窄）。
- **SOM**：无结论；个人/开源项目以「首年付费用户数」而非收入规模为验证指标。
- **单位经济**：BYOK 下无模型成本，毛利结构接近纯软件；主要成本为渠道抽成（15–30%）、云/同步成本、开发者时间。模型成本由用户自付，无「模型成本吃掉毛利」的 AI 应用典型风险。
- **竞争参考定价**（公开资料，2026-08-27）：蒙哥买断 €2.99≈¥18；欧路 AI 会员 ¥28/月、¥168/年；沉浸式翻译 ¥69/月、¥588/年；彩云小译 VIP ¥12/月、¥108/年。大陆阅读/翻译工具「月 ¥10–30、年 ¥100–170」接受度较高。

## 5. 竞品与替代方案

（详见 `竞品分析.md`，三层结构摘要）

- **直接竞品**：蒙哥阅读器（词频分级颜色 + 背单词，iOS 买断，无官方安卓）、沉浸式翻译（双语对照 + 20 引擎 + 多平台，会员制）。
- **间接竞品**：欧路词典（词典+取词+背单词）、KOReader（开源 + 插件生态，已现「虚线淡下划线翻译记忆」）。
- **替代方案**：纸质+手动查词、微信读书/Apple Books+系统取词、通用大模型粘贴翻译、网页双语导出。
- **缺口机会**：无人做「词性/难度/是否点击」多维切换的虚线 + 小字标注 + 段译插入的组合；开源 BYOK 与闭源订阅形成定位区隔。
- **最大威胁**：沉浸式翻译 / KOReader 若快速跟进「虚线标注」形态。

## 6. 差异化命题（可测）

**命题**：「彩色虚线 + 小字标注 + 段译插入」的阅读方式，比「词频高亮」和「译文对照」更能让泛英语阅读者持续读英文原版书。

- 对比对象：蒙哥（高亮）、沉浸式翻译（对照）。
- 测试条件：同一英文原版书段落，三种呈现并列。
- 指标：用户首选 C（虚线+小字+段译）比例、可读性评分、付费意愿。
- 通过阈值：≥60% 首选 C（需用户确认）。
- 证据状态：待验证。

## 7. 技术可行性：3 / 5

- EPUB 为 HTML/CSS 结构，单词级 inline 虚线 + 小字标注理论可行；有成熟渲染库。
- 但「多维分类着色 + 段译插入」的移动端高质量实现、不破坏排版、长文性能是**未验证组件**。
- 大模型翻译为成熟 API，多模型可切换缓解单点依赖。
- **AI 模型依赖风险**：翻译完全依赖第三方 API；被基础模型吞并风险低（价值在阅读标注交互，非模型）。
- **首版砍 PDF（仅 EPUB/TXT）可将技术可行性升至 4**。

## 8. 商业可行性：2 / 5

- BYOK 无模型成本，毛利结构健康。
- 竞品付费先例存在（买断 ¥18、订阅 ¥12–35/月）。
- 但「开源 Open Core + 大陆安卓渠道订阅」转化与分发未验证；开源付费意愿偏低；个人兼职无获客预算。
- 变现模式：Open Core（开源免费 + 高级功能订阅解锁）。定价建议低于闭源竞品（如 ¥12/月、¥88/年档，需用户确认）。

## 9. 合规与风险

- **隐私**：BYOK 模式下模型 key 需本地安全存储；若做账号同步/词典缓存，涉及 PIPL（《个人信息保护法》）合规。
- **内容合规**：大陆 App 需 ICP/备案；「个人导入电子书」风险可控，但不可内置盗版书源、不可分享译文/书。
- **应用商店审核**：App Store 与大陆安卓渠道对「开源 App 内购订阅」政策与抽成不同（待验证）。
- **开源许可证**：需选定许可证（MIT/Apache 宽松 vs GPL/AGPL 强 copyleft），影响商业化的 Open Core 边界。
- **模型合规**：接国内模型需符合国内生成式 AI 监管；接海外模型存在跨境数据传输与可达性风险，由用户自担（BYOK）。

## 10. MVP 与验证计划

（详见 `验证计划.md`）

- **MVP**：Android 首发 EPUB/TXT 阅读器，含点查弹窗、单词级彩色虚线 + 小字标注（词性 + 是否点击两档起步）、整段翻译插入、多模型 BYOK。个人兼职 4–8 周。
- **最优先 cheapest tests（1 周内）**：
  - V1 交互对比（静态原型，3 种呈现，5–8 人访谈）→ 验证「虚线+小字+段译」是否真被偏好。
  - V2 落地页 + waitlist → 验证付费意愿。
- **三类门槛**：
  - 继续：V1 ≥60% 首选 C，且 V3 MVP 7 日留存达标。
  - 调整：V1 未达首选但「段译插入」单项高 → 砍着色，聚焦段译单点。
  - 暂停（kill）：V1 + V2 均未通过 → 差异化交互非真痛点。
