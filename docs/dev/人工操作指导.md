## 1. 本文件解决什么

本产品技术栈为：**Kotlin 壳（Android 首发）+ WebView（foliate-js 渲染）+ DOM 标注（`<ruby>`/CSS 虚线）+ ECDICT 本地词表 + BYOK 模型 API**。本文件告诉你在 IntelliJ IDEA Ultimate 里怎么把这套东西搭起来、怎么分阶段开发、怎么调试，不含逐行代码。

## 2. 环境准备

### 2.1 必装软件
- **IntelliJ IDEA Ultimate**（最新稳定版）。
- **JDK**：JDK 17+（Android 构建需要，建议 17 或 21 LTS）。
- **Android SDK**：IDEA Ultimate 不像 Android Studio 那样自动引导安装 SDK，需自行装：装 SDK 命令行工具 `sdkmanager`（或安装一次 Android Studio 借用其 SDK），包含 `platform-tools`（adb）、`platforms;android-XX`、`build-tools`、模拟器镜像。
- **Node.js**：LTS 版本（Web 层与工具链需要）。

### 2.2 插件（关键）
- **Android 插件**（IDEA Ultimate 内置，若未启用到 Plugins 开启）。
- **Kotlin 插件**（内置）。
- JS/HTML 支持（内置，写 Web 层用）。
- 可选：`Markdown` 预览插件（查看 docs/）。

### 2.3 关键配置核对
- `JAVA_HOME` 指向 JDK；`ANDROID_HOME`/`ANDROID_SDK_ROOT` 指向 SDK（IDEA 的 Project Structure → SDK 里也要认到）。
- Gradle 走国内镜像（如腾讯/阿里 maven 镜像）以加速依赖下载。
- npm 走国内镜像（可选）。

## 3. 仓库与目录结构（建议）

```
mobile-english-reader/
├── android/                 # Kotlin 壳层（Gradle 工程）
│   └── app/src/main/...

│   ├── reader/              # EPUB 渲染 + 分页
```

说明：目录按技术方案第 4 章模块划分对齐——壳层、Web 层、词典、桥接各自成目录，便于后续 iOS 复用 Web 层。

## 4. 分阶段开发（M1 → M2 → M3）

> 每阶段都要先跑通对应的「风险验证门槛」（技术方案第 7 章），再做功能。

### 4.1 M1 技术 spike（1–2 周）——先验证再投入
**目标**：验证 3 个承重风险 R1/R2/R4，不做完整功能。

- 步骤 1：在 `web/` 里用 foliate-js 加载一个标准 EPUB，确认能在浏览器/WebView 分页显示。
- 步骤 2：手工在一段文本上叠 `<ruby>` 注解（`ruby-position: under`）+ CSS 虚线边框，确认「词下小字」在 Android WebView 里渲染正确。
- 步骤 3：写一个最小脚本，调用 1–2 家低价模型（如 Qwen3-Plus / 豆包 Lite / GLM-4-Air），要求模型对段落返回结构化划线段（text_range/type/pos/difficulty/gloss），验证 JSON 可解析率。
- 步骤 4：在 Kotlin 壳里开一个 WebView 加载 `web/`，跑通壳层↔Web 层的消息桥接（调用→返回）。

**通过标准**（对应技术方案 R1/R2/R4 阈值，需你确认）：
- 模型结构化返回可解析率 ≥ 80%（否则启用「翻译为主 + 本地词表切分」降级）。
- WebView 分页 + 单屏标注无明显卡顿/崩溃。
- `<ruby>` 词下小字在 WebView 渲染可读。

### 4.2 M2 MVP（4–8 周）——做出可用首版
**范围**：EPUB/TXT 导入 + 点查弹窗 + 划线（词性 + 是否点击两档起步）+ 段译插入 + BYOK + 订阅开关。

按模块推进顺序建议：
1. **壳层文件导入**：EPUB/TXT 导入、解压（zip.js）、读取。
2. **本地词表**：ECDICT 转 SQLite，实现词性/词频/高考四六级查询与释义兜底。
3. **Web 渲染 + 标注引擎**：段落渲染 → 模型划线（带上下文）→ DOM 叠加 `<ruby>` 标注 → 颜色按激活分类渲染。
4. **点选查词**：选中 Range → 壳层调模型/本地词典 → 弹窗。
5. **段译插入**：选中段 → 译文插入本段后（分页模式下验证版式）。
6. **BYOK 模型配置**：多服务商适配 + key 安全存储 + 连接测试。
7. **订阅开关**：免费版 vs 订阅版功能边界（内购渠道后续接）。

**验收**：逐条过 PRD 第 6 章 P0 功能的验收标准 + 第 7 章关键非功能项（冷启动 ≤2s、弹窗 ≤300ms、模型失败不崩溃、key 不泄露）。

### 4.3 M3 内测/发布
- 灰发（小范围分发 APK）→ 收集崩溃与留存。
- 开源仓库上架（MIT）→ README + 贡献指南。
- Android 应用商店上架（合规与支付渠道确认后）。

## 5. 调试要点（IntelliJ IDEA Ultimate）

### 5.1 Kotlin 壳层
- 用 IDEA 内置 AVD 管理器建模拟器，或真机（USB 调试 + adb）。
- 构建：`Build > Make Project` 或直接点 Run；断点调试直接 `Debug`（IDEA 对 Kotlin 断点/变量检查是原生的）。
- 日志走 Logcat 工具窗口，过滤应用包名。

### 5.2 Web 渲染层
- 关键技巧：Android WebView 开 `WebView.setWebContentsDebuggingEnabled(true)`，然后在桌面 Chrome 打开 `chrome://inspect` 调试 WebView 内的 DOM/JS（IDEA 本身不直接调试 WebView DOM）。
- 纯 JS 逻辑先在桌面 Chrome 里用 IDEA 内置 HTTP Server / 简单静态服务器预览调试，再进 WebView。

### 5.3 桥接
- 给壳层↔Web 层的消息加统一日志（去标识化，**不含 API key 与书内容**），便于排查。
