## 1. Eread 是什么

Eread 是一款**手机英文原版书阅读器**。它的核心思路是：让读者在**不跳出原文**的前提下完成查词和看译文——把阅读的「被打断」降到最低。

主要能力：

- **导入并阅读** EPUB / TXT 英文电子书。
- **点选查词**：点一下单词，弹窗即显示词性、音标和中文释义。
- **段落划线标注**：点段落前的「译」按钮，系统会在原文上用**虚线**划出有意义的单词和词组，并在虚线下以**小号字标注中文释义**，把原文变成可"一眼看懂"的学习文本。
- **主题与排版自定义**：浅色 / 深色 / 护眼主题、字号、颜色、阅读壁纸、横向翻页 / 纵向连贯等。

> 说明：查词和划线标注由**你自带的模型 Key**（BYOK，Bring Your Own Key）驱动，App 本身不内置翻译额度，**模型调用费用由你自行承担**（见[第 7 章](#7-配置-api-keybyok)）。未配置 Key 时，阅读、导入、进度等本地功能不受影响，仅 AI 相关的查词 / 标注不可用。

## 2. 快速开始（首次使用）

1. **打开 App**，进入「书架」首页。书架已预置两本样书：《香料与狼 1》(中英互译)《Spice & Wolf XI》(纯英文)，可直接点开体验。
2. **（推荐）配置 API Key**：进入「用户」页 →「设置」→「翻译 API 配置」，填入你的模型 Key 并保存。这样点选查词和段落标注才能工作。
3. **点开一本书**，进入阅读页。
4. **点正文中的单词** → 查看弹窗释义；**点段落前的「译」按钮** → 查看整段划线标注。
5. **导入自己的书**：回到书架，点右下角「+」或「添加图书」，从系统文件选择器选择 EPUB / TXT 文件。

## 4. 书架页

书架页把所有书（预置书 + 你自己导入的书）统一放在同一个列表里管理。

### 4.1 打开图书

点任意书籍卡片即可打开并进入阅读页。没有封面的书会显示书名的首字。

### 4.2 导入图书

点右下角悬浮「+」按钮，或书架末尾的「添加图书」卡片，会唤起系统文件选择器，选择 **EPUB** 或 **TXT** 文件即可导入。导入成功后 App 会自动尝试提取书籍封面并显示在卡片上。

> 导入功能需在 App 内使用（依赖系统文件选择器），在浏览器里直接打开 Web 页面无法导入。

### 4.3 删除图书

**长按**书籍卡片约 0.5 秒，弹出确认框后确认删除。

- 删除**预置书**：仅把它移出书架（可恢复，不会重复自动加回）。
- 删除**导入的书**：同时删除本地存储的书文件与其缓存，**不可恢复**。

## 5. 阅读页

打开一本书后进入阅读页，顶部是书名，底部是工具栏，中间是正文。

### 5.1 翻页与导航

- 底部工具栏左侧「上一页 / 下一页」按钮切换页面。
- 工具栏中间显示当前页码（如 `3 / 120 页`）或阅读进度百分比。
- 点击正文**空白处**，可显示 / 隐藏顶栏与底栏（翻页或滚动时顶栏、底栏会自动隐藏，给你干净的阅读画面）。
- 左上角返回键返回书架。
- 手机物理返回键：在阅读页会先返回书架。

### 5.2 点选查词

**点一下正文中的某个英文单词**，会立即弹出释义弹窗，显示：

- 单词原文
- 词性（noun / verb / adj / adv 等）与音标（如模型提供）
- 中文释义
- 「在网页中搜索」入口

点「在网页中搜索」会用你设置的搜索网站（见 [6.6](#66-查词相关设置)）打开该词的网页查询。弹窗约 5 秒后自动消失，点其它单词或空白处也会关闭。

> 查词需要网络和已配置的 API Key；未配置或网络异常时会提示，阅读本身不受影响。

### 5.3 段落标注（「译」按钮）

这是 Eread 的核心功能。每个段落前都有一个蓝色小按钮 **「译」**：

1. **点「译」**：App 会调用你配置的模型，识别该段落中有学习价值的**单词和词组**，在原文上用**虚线**划出，并在虚线下方用**小号字**显示中文释义（按钮会短暂显示 `…`，完成后变为 `✓`）。
2. **再点「✓」**：撤销标注，恢复原文。

标注结果会**按书缓存**：同一段落再次标注不会重复调用模型（不重复计费），重新打开页面也能直接恢复。

> - 标注的是「有意义的词/词组」（如短语动词、固定搭配、专有名词），而不是机械地每个词都划。
> - 虚线颜色当前跟随正文文字颜色；虚线下释义小字的颜色可在「功能菜单」或「设置」里的「注释文字颜色」调整。

### 5.4 功能菜单

阅读页底部工具栏右侧的 **☰** 按钮打开功能菜单，包含：

| 项目 | 说明 |
|---|---|
| **跳页** | 输入章节序号（从 0 起）跳转到对应章节 |
| **背景颜色** | 选择正文背景色（色块） |
| **文字颜色** | 选择正文文字颜色 |
| **文字大小** | 拖动滑杆调整正文字号（14–28） |
| **注释文字颜色** | 设置虚线下释义小字的颜色 |
| **注释文字大小** | 释义字号 = 正文 × 倍数（0.40–0.80，小于 1） |
| **浏览模式** | 横向翻页 / 纵向连贯（见 6.5） |

> 功能菜单里的设置与「设置页」是**同一份设置**，在任一处修改，另一处会同步生效。

### 5.5 阅读进度

App 会**自动保存**每本书的阅读位置，退出后重新打开会恢复到上次读到的位置。

## 6. 用户页与设置

进入「用户」页 → 点「设置」，打开统一设置页。各项说明如下：

### 6.1 主题

一键切换三套预设：**浅色 / 深色 / 护眼（羊皮纸色）**。切换主题会同步设置背景、文字、卡片、按钮等整套配色。

### 6.2 阅读壁纸

- **导入壁纸图片**：从相册 / 文件选择一张图片作为阅读页背景。
- **清除**：移除壁纸，回到纯色背景。
- **模糊度**：壁纸模糊程度（0–20）。
- **遮罩透明度**：在壁纸上叠加一层遮罩的透明度（0–80%），保证文字可读性。

### 6.3 页面背景（书架 / 用户页）

- 选择书架页与用户页的纯色背景，或导入一张「页面壁纸」。
- 与阅读页背景相互独立，互不影响。

### 6.4 文字与颜色

- **背景颜色**、**文字颜色**：阅读正文的配色。
- **文字大小**：正文字号（14–28）。
- **注释文字颜色**、**注释文字大小**：段落标注释义小字的颜色与字号倍数。

### 6.5 浏览模式

- **横向翻页**：像纸质书一样左右翻页（默认）。
- **纵向连贯**：整本书上下连续滚动阅读。

### 6.6 查词相关设置

- **单词搜索跳转网站**：点查词弹窗里的「在网页中搜索」时打开的网站，可选 **Google 翻译 / 有道词典 / 欧路词典**。
- **查词弹窗位置**：弹窗显示在「页面左下角」或「单词周围」。

## 7. 配置 API Key（BYOK）

Eread 采用 **BYOK** 模式：模型推理由你的 Key 驱动，费用由你承担。查词与段落标注需要先在这里配置好模型。

进入「用户」→「设置」→「翻译 API 配置」，填写：

| 字段 | 说明 | 默认值 |
|---|---|---|
| **Base URL** | 模型服务地址（OpenAI 兼容接口） | `https://api.deepseek.com` |
| **模型** | 模型名称 | `deepseek-chat` |
| **API Key** | 你的模型密钥 | 无 |

填写完成后点 **「保存配置」**。保存成功后按钮短暂显示「✓ 已保存」。

**安全说明：**

- API Key 会使用 **Android Keystore 的 AES-GCM 加密**存储在本机，**不以明文落盘**，也不会写入日志、崩溃上报或上传到任何第三方服务器。
- Key 只在本机用于向模型服务发起请求（附在请求头 `Authorization` 中）。

> 建议使用支持「OpenAI 兼容 `/chat/completions` 接口」的服务与模型（如 DeepSeek 等）。不同的 Key 请按对应服务商文档填写 Base URL 与模型名。

## 8. 常见问题（FAQ）

**Q：为什么点单词 / 点「译」没反应或提示错误？**
A：查词与标注依赖外部模型，请确认：① 已配置有效的 API Key；② 网络可用；③ Key 额度充足。错误会以提示形式反馈，阅读本身不受影响。

**Q：没有配置 Key 能使用吗？**
A：可以。导入、阅读、进度、主题、壁纸等本地功能完全不受影响；仅「点选查词」和「段落标注」不可用。

**Q：导入的书在哪里？会占我空间吗？**
A：书文件存储在本机 App 的本地存储中，属于本地文件，卸载 App 即清除。

**Q：标注 / 查词会不会重复收费？**
A：段落标注结果会按书 + 段落缓存，同一段再次标注不会重复调用模型。查词每次点击都会发起一次请求。

**Q：为什么在浏览器里打开页面无法导入书？**
A：导入、查词、标注等功能依赖 App 的原生能力（文件选择器、模型调用），请在 App 内使用。

## 9. 数据与隐私

- **无账号体系**：单机优先，无需注册登录即可使用。
- **数据本地存储**：书籍文件、阅读进度、标注缓存、设置等全部保存在本机（IndexedDB / localStorage / 系统安全存储），不上传开发者服务器。
- **API Key 加密存储**：使用 Android Keystore（AES-GCM）加密，不明文落盘、不进日志。
- **模型调用**：仅把你查询的**单词 / 段落文本**发送到你所配置的模型服务商；这是由你自己的 Key 与所选服务商之间的调用，Eread 不中转、不代传你的书内容到开发者服务器。
- **卸载即清除**：卸载 App 会清除本地书籍、进度、标注与设置。

## 10. 当前版本说明与已知限制

本说明对应 **0.2.0（M2 MVP）** 版本，属于早期可用版本，部分能力尚在规划或完善中：

- **四色分类标注尚未开放切换**：产品规划了按「词性 / 是否点击查看 / 高考四六级 / 词频」四类维度给划线**上不同颜色**的能力，代码已预留颜色映射，但当前版本尚未在界面开放分类切换入口——目前标注为统一虚线 + 小字释义。
- **首版不支持**：PDF、语音朗读（TTS）、背单词复习系统、付费书城、账号同步 / 云端生词本等（详见产品需求文档）。
- **标注样式细节**：在部分设备 / 系统 WebView 上，虚线与释义小字的相对位置可能存在轻微差异。

> 后续版本将逐步开放四色分类切换、标注导出、多模型切换等能力，敬请期待。
